# Команды

| Команда | Назначение |
| --- | --- |
| `ZBP_SHOW_PANEL` | Открыть основное окно пакетной печати по рамкам. |
| `SPDSPRINT` / `SPDS_PRINT` | Открыть режим пакетной печати СПДС. |
| `ZBP_RECTANGLE_BATCH_PLOT` | Открыть пакетную печать по прямоугольникам. |
| `ZBP_SINGLE_PLOT` | Напечатать один выбранный лист. |
| `ZBP_ADD_TITLE_BLOCK` | Добавить определение рамки в библиотеку. |
| `ZBP_MANAGE_LIBRARY` | Открыть библиотеку рамок. |
| `ZBP_SETTINGS` | Открыть параметры плагина. |
| `ZBP_OPEN_CONFIG` | Открыть папку пользовательских настроек и библиотеки. |
| `ZBP_SHORTCUT_SETTINGS` | Настроить сокращённые команды. |
| `ZBP_ABOUT` | Показать сведения о плагине. |

В параметрах печати доступны, в частности, печать прозрачности, печать весов линий, исключение внешней границы рамки и добавление закладок при объединении PDF.
